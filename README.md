# SASEHACK2026

Solo AI hackathon workspace.

## Operating model
- **Lead / PM** — requirements, scope, priorities, and task queue
- **Engineer** — implementation and integration
- **QA / Debugger** — tests, defects, and demo reliability
- **Pitch / Docs** — README, architecture story, demo, and submission narrative

## Core rule
Build the smallest working vertical slice first:

**Input → AI/Agent → Action/Result → Visible Output**

Challenge-specific architecture will be selected after the official prompt and judging rubric are reviewed.
