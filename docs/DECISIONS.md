# Decision Log

## D-001 — Solo-first workflow
**Decision:** Use a Lead → Engineer → QA → Pitch workflow with the human as Tech Lead.

**Reason:** Reduce coordination overhead while retaining explicit review gates.

## D-002 — Vertical slice first
**Decision:** Prioritize Input → AI/Agent → Result → Visible Output before secondary features.

**Reason:** Establish a demonstrable product early and reduce integration risk.

## D-003 — Challenge-neutral initialization
**Decision:** Do not choose frameworks or architecture before reviewing the official challenge.

**Reason:** Avoid sunk-cost implementation that does not serve judging criteria.
